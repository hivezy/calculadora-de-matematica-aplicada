# Calculadora de Matemática Aplicada

> *Uma calculadora desenvolvida por Hivezy.*

Projeto desenvolvido com o objetivo de criar uma calculadora intuitiva para auxiliar no estudo de Matemática Aplicada e, simultaneamente, servir como projeto prático para o aprendizado de programação.

A proposta não é apenas obter resultados matemáticos, mas desenvolver uma ferramenta capaz de auxiliar na compreensão dos processos utilizados para chegar a esses resultados.

## Objetivos

- Aplicar conceitos de Matemática Aplicada através da programação;
- Desenvolver e praticar lógica de programação;
- Criar uma calculadora simples e intuitiva;
- Implementar os conteúdos progressivamente conforme são estudados;
- Permitir a conferência de exercícios e cálculos;
- Futuramente, apresentar a resolução passo a passo das operações.

## Conteúdos previstos

Com base nos conteúdos da disciplina de Matemática Aplicada, o projeto deverá abranger:

### Cálculos Numéricos
- Operações básicas;
- Expressões numéricas;
- Potenciação;
- Radiciação;
- Regra de sinais;
- Operações com números decimais.

### Conjuntos Numéricos
- Números naturais;
- Números inteiros;
- Números racionais;
- Números irracionais;
- Números reais;
- Classificação de números.

### Relações e Funções
- Relações;
- Funções;
- Cálculo de funções.

### Álgebra Linear
- Matrizes;
- Determinantes;
- Sistemas lineares.

### Razões e Proporções
- Razão;
- Proporção;
- Aplicações práticas.

### Geometria Aplicada
- Áreas;
- Volumes;
- Aplicações em situações práticas.

## Modos planejados

### Modo Calculadora

Destinado à realização rápida de cálculos, apresentando diretamente o resultado da operação.

### Modo Aprendizado

Destinado ao estudo, apresentando não apenas o resultado, mas também o desenvolvimento da resolução sempre que possível.

## Filosofia de desenvolvimento

O desenvolvimento seguirá, sempre que possível, a seguinte sequência:

**Entender o conteúdo matemático → transformar em lógica → programar → testar → explicar o processo**

O objetivo é evitar depender inicialmente de bibliotecas que realizem automaticamente toda a matemática, priorizando a compreensão e implementação dos algoritmos.
